# Planning

Use this information to plan the product installation and prepare the target environment.

Completing the planning activities before installation can help you identify requirements, dependencies, and required resources.

## Planning checklist

Use the following table to track the planning activities for your installation.

| Planning activity | Description | Owner | Status |
|---|---|---|---|
| Review the system requirements | Verify that the target environment meets the supported hardware and software requirements. | System administrator | Not started |
| Confirm administrator access | Ensure that the person performing the installation has administrator privileges on the target system. | System administrator | Not started |
| Obtain the installation package | Download the appropriate installation
