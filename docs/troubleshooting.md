# Troubleshooting

This section provides solutions to common issues that you might encounter while using the product.

## Common issues

<details>
<summary>Why can't I push my changes?</summary>

Make sure that you:

1. Have committed your changes.
2. Are connected to the correct remote repository.
3. Have permission to push to the repository.
4. Have resolved any merge conflicts.
5. Are using the correct branch.

</details>

<details>
<summary>Why can't I pull the latest changes?</summary>

Make sure that you:

1. Are connected to the correct repository.
2. Have network connectivity.
3. Have permission to access the repository.
4. Have resolved any local changes that might prevent the pull operation.
5. Are pulling from the correct branch.

</details>

<details>
<summary>Why are my changes not appearing in the published documentation?</summary>

Check the following items:

1. Verify that your changes were committed.
2. Verify that your changes were pushed to the repository.
3. Confirm that the build pipeline completed successfully.
4. Verify that the correct branch was published.
5. Refresh your browser and clear the cache if necessary.

</details>

<details open>
<summary>Why is the documentation build failing?</summary>

Review the build logs and verify that:

1. All required files are present.
2. Markdown syntax is valid.
3. Links and references are correct.
4. File names match the referenced paths.
5. Required metadata and front matter are included.

</details>
