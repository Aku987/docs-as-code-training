# Administration

Use this information to administer the product, manage users and access, monitor product activity, and maintain the product environment.

> [!Note] Important
> You must have the appropriate administrator permissions to perform the tasks described in this section.

## Administration task list

Use the following task list to track the administrative activities for your environment.

### Initial configuration 

- [ ] Review the product configuration requirements.
- [ ] Configure the general product settings.
- [ ] Configure authentication.
- [ ] Configure network and security settings.
- [ ] Configure required integrations.
- [ ] Set up email and product notifications.
- [ ] Verify that the configuration is working as expected.

For configuration instructions, see configuration.md.

### User management

- [ ] Create user accounts.
- [ ] Update existing user accounts.
- [ ] Deactivate accounts that are no longer required.
- [ ] Assign roles and permissions
